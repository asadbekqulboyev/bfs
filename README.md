# 🎮 BFS Pathfinding Game Edition

> Gridda BFS (Breadth-First Search — Kenglik bo'yicha qidiruv) algoritmining jonli, silliq harakatlar va haqiqiy o'yin tovushlari bilan vizualizatori.

![Audio](https://img.shields.io/badge/Web%20Audio-Synthesizer-purple)

## 🚀 Imkoniyatlar

- **⚡ Asl Misol Andozasi (10x5 Grid):** Foydalanuvchi kodi asosidagi `10 × 5` grid, devorlar (`X`), start (`S`) va maqsad (`G`).
- **🤖 Silliq Harakatlanuvchi Qahramon (Hero Runner):** Yo'l topilganda tanlangan qahramon (Kiber-Bot, Plazma Shar, Dron, Piksel Qahramon) butun yo'l bo'ylab silliq harakatlanadi.
- **🔊 Haqiqiy O'yin Audio Sintizatori (Web Audio API):**
  - Radar skanerlash pinglelari
  - Navbatga qo'shish laser tovushlari
  - Qahramon qadamlarida ko'tariluvchi musiqiy pentatonik ohanglar
  - G'alaba qozonilganda arcade tantana fanfarasi
  - Kiber-sint arpejio fon musiqasi (BGM)
- **✨ Zarrachalar Tizimi (Canvas FX):** Har bir bosilgan qadamda oltin uchqunlar va nishonga yetganda bayram feyerverklari.
- **🕹️ Jonli FIFO Navbat (Queue Inspector):** `queue.shift()` va `queue.push()` harakatlarini jonli chiplarda kuzatish.
- **🖱️ Interaktiv Devor Chizish & Drag-and-Drop:** Start/Goal nuqtalarini surish, devor chizish va o'chirish.
- **🌀 Labirint (Maze) va Andozalar Generator:** Tasodifiy to'siqlar, tor yo'laklar, zig-zag labirintlar.

## 🛠️ Ishga tushirish

