Algoritm va Kod Mantiqi

1
Navbatdan olish (FIFO): const [r, c] = queue.shift()

Navbat boshidagi birinchi katak olinadi va skanerlanadi.

2
To'siq va Chegara tekshiruvi: grid[nr][nc] === 'X' || nr < 0...

Devorlar va chegara tekshirilib, o'tib bo'lmaydigan joylar o'tkazib yuboriladi.

3
Takrorlanishning oldini olish: visited.has(`${nr},${nc}`)

Bir marta ko'rilgan katak qayta navbatga qo'shilmaydi (optimal yo'l garovi).

4
Ota-onani saqlash va Navbatga qo'shish: parent[key] = `${r},${c}`; queue.push([nr,nc])

Yo'lni qahramon bosib o'tishi uchun har bir katakning ota-onasi saqlanadi.

// Siz taqdim etgan BFS kodi:
function bfs(grid, start, goal) {
  const queue = [start];
  const visited = new Set();
  visited.add(`${start[0]},${start[1]}`);
  const parent = {};
  const rows = grid.length;
  const cols = grid[0].length;
  const directions = [[-1, 0], [1, 0], [0, -1], [0, 1]];

  while (queue.length > 0) {
    const [r, c] = queue.shift();
    if (r === goal[0] && c === goal[1]) {
      return reconstructPath(parent, start, goal);
    }
    for (const [dr, dc] of directions) {
      const nr = r + dr;
      const nc = c + dc;
      if (nr < 0 || nr >= rows || nc < 0 || nc >= cols) continue;
      if (grid[nr][nc] === 'X') continue;
      const key = `${nr},${nc}`;
      if (visited.has(key)) continue;
      visited.add(key);
      parent[key] = `${r},${c}`;
      queue.push([nr, nc]);
    }
  }
  return null;
}
